## 0. 任务与交付物

制作一份**移动端高保真可点击原型**：

- 视口：iPhone 尺寸 **390 × 844**，竖屏，仅简体中文
- 形式：HTML/CSS/JS（可单文件或按页拆分），无需后端，用内置示范数据驱动
- 页面之间可以真实点击跳转，走通第 7 节全部演示流程；不允许出现点了没反应的按钮——次要功能可弹出「原型中暂未实现」的轻提示
- 示范数据必须是脱敏的虚构数据（虚构人名、医院名、数值合理），禁止真实手机号与真实报告内容
- **设计质量优先于功能数量**：这份原型的用途是确认视觉与交互方向

### 分阶段交付（强制）

| 阶段 | 交付内容 | 验收重点 |
|---|---|---|
| **阶段 A** | 仅 P4「此刻」+ P6「报告确认」 | 气质、留白、数字排版、解读区块；不对则停工改这两页 |
| **阶段 B** | 其余 10 页 + 6 条演示流程全部可点通 | 视觉一致、红线零命中、自查清单全勾 |

未完成阶段 A 验收前，不得铺开阶段 B。

## 1. 产品背景（30 秒读懂）

**芽纪是属于一个家庭的孕育档案与解读助手**，覆盖备孕、孕期、产后、宝宝 0–1 岁。

用户是准爸妈夫妻二人。他们的处境：跑医院攒下一大袋报告；见医生只有两三分钟，出了诊室就忘记叮嘱；报告看不懂，病历上一个「先兆流产」的通用写法能把全家吓哭；不知道下次检查什么时候、带什么；几个月的报告串不起来结论。

产品让用户把报告（拍照）、医生的话（录音）、在家测的数据交给它，它记得完整历史，用白话讲清楚：**发生了什么、这个词什么意思、下一步是什么、下次带什么。**

**产品红线**：它不诊断、不给行动建议（该吃什么药 / 该不该做检查）、不评判医生。所有 AI 内容只做两件事——解释术语与报告、提示档案里的事实。

## 2. 设计方向（唯一气质，不可混搭）

**安静的系统级工具**——像 iOS 自带的「健康」App 那样克制、可信、精准。  
**不是**母婴行业常见的运营型 App，**也不是**医疗仪表盘，**不是**内容社区。

### 四条原则

1. **内容即界面**。孕周数字、指标数值、下一步事项就是主角；装饰只建立层级，绝不与内容抢注意力。
2. **秩序感**。同一间距、圆角、分割规则贯穿全部页面；任意截图都应像同一人设计。
3. **留白是功能**。首屏宁可少放一个模块，也不允许拥挤；区块之间呼吸感充足。
4. **情绪安抚**。用户常在焦虑时打开：低饱和、柔和层次、不用红色大警告（除删除外）。

### 气质防跑偏（写死）

整份原型只允许上述一种气质。下列「混搭」一律禁止：

| 禁止混入 | 典型症状 |
|---|---|
| 运营型母婴 App | Banner、轮播、九宫格、资讯流、粉嫩插画、打卡勋章 |
| 通用 AI 审美 | 紫白渐变、玻璃拟态滥用、多层阴影、发光、胶囊标签堆、Inter/Roboto 花哨搭配 |
| 奶油杂志风 | 暖奶油底 `#F4F1EA` + 衬线大标题 + 陶土主色整页铺开 |
| 报纸编辑风 | 发丝线密排、零圆角、多栏密文 |
| 医疗仪表盘 | 首屏多组 KPI 卡片、统计条矩阵、无关快捷入口 |

执行上参考 Apple HIG 的导航、列表与层级习惯，但品牌色与细节要有芽纪自己的性格——**不做 iOS 皮肤复刻**。

## 3. 视觉规范

### 3.1 色彩（必须以 CSS 变量定义）

| 变量 | 值 | 用途 |
|---|---|---|
| `--brand` | `#3F6F5B`（深苔绿） | 关键操作、选中态、品牌标识 |
| `--brand-soft` | `#D7E6DD` | 轻标签底、选中背景 |
| `--accent` | `#C4785A`（陶土色，极少量） | 仅低置信度点、待办小圆点；**禁止作主色铺底** |
| `--bg` | `#F2F5F3`（冷雾绿灰） | 页面背景 |
| `--surface` | `#FFFFFF` | 列表行、分组容器 |
| `--text` | `#1C2421` | 主文字 |
| `--text-muted` | `#5E6B65` | 次要文字 |
| `--border` | `#D5DED8` | 细分割线 |
| `--danger` | `#B42318` | 仅删除 / 退出 |

规则：绿色系主导 + 极少量陶土点缀；**禁止**引入紫色、蓝紫渐变、大面积高饱和色。深色模式不做。

建议变量片段（可直接粘贴）：

```css
:root {
  --brand: #3F6F5B;
  --brand-soft: #D7E6DD;
  --accent: #C4785A;
  --bg: #F2F5F3;
  --surface: #FFFFFF;
  --text: #1C2421;
  --text-muted: #5E6B65;
  --border: #D5DED8;
  --danger: #B42318;
  --radius-group: 16px;
  --radius-btn: 12px;
  --radius-tag: 8px;
  --page-pad-x: 20px;
}
```

### 3.2 字体与数字（数字是明星）

- 中文正文：系统字体栈，`PingFang SC, -apple-system, BlinkMacSystemFont, "Helvetica Neue", sans-serif`
- **禁止**引入 Inter / Roboto / Arial 作为展示字体；禁止花哨中文网字
- **关键数值**（孕周、胎心、体重、血压、双顶径等）：
  - 字号明显大于正文（见下表）
  - `font-weight: 500–600`
  - `font-variant-numeric: tabular-nums`
  - 单位用小一号 `--text-muted`，紧跟数值，不换行截断
- 字号阶（px）：

| 用途 | 字号 |
|---|---:|
| 页面大标题（此刻 / 档案…） | 34 |
| **孕周主数字**（「24」） | **48–56** |
| 区块标题 | 22 |
| 指标卡最新值 | 28–32 |
| 正文 | 17 |
| 次要 | 15 |
| 说明 / 标签 / 出处 | 13 |

- 行高 1.4–1.6；大标题页用 iOS 式大标题 + 一行浅色副文案

### 3.3 形状、间距与光影

- 间距：4 的倍数；左右边距 20px；区块间距 24–32px
- 圆角：分组 16 / 按钮 12 / 标签 8，**全站统一，禁止混用**
- 阴影：几乎不用；最多 `0 1px 2px rgba(0,0,0,0.04)`；禁止多层重阴影与发光
- 分割：行间 0.5–1px `--border`（左缩进与文字齐）；组间靠背景色间隔
- 图标：细线性（SF Symbols 感，stroke 1.5–2px），单色；**禁止 emoji 当图标、彩色拟物、图标风格混用**
- 标签：小圆角矩形即可；禁止满屏 `rounded-full` 胶囊堆

### 3.4 动效

克制、有目的，CSS 即可：

- 页面切换：淡入 + 上移 8–12px，200–250ms，ease-out
- 「此刻」加载：区块 stagger 淡入（延迟 40–60ms）——**全产品唯一允许精心编排的入场**
- 按钮按下：scale(0.97)；归档成功：简洁对勾 + 轻提示
- 录音中：品牌色低透明呼吸波纹，安静不焦躁
- 禁止：弹跳、旋转入场、视差、粒子、长动画干扰阅读

## 4. 布局与组件规范

- **底部 Tab**：此刻 · 档案 · 健康 · 我的；中央上浮圆形「＋」（`--brand`），点开底部弹层
- **添加菜单**顺序（出诊优先）：就诊录音 → 上传检查报告 → 记下医生叮嘱 → 记录用药 → 记居家监测 → 手动事件与提醒（次要，置底）
- **分组列表**为主容器：白底圆角组 + 13px 组标题 + 行左图标右箭头；**能用列表就不用卡片堆叠**；卡片仅用于可交互块
- **按钮**：主按钮每屏最多 1 个（品牌填充、白字、高 48）；次按钮文字或 `--brand-soft` 底；危险操作为红字文字按钮 + 二次确认
- **表单**：标签在上；聚焦品牌描边；错误在字段下；触控 ≥ 44px
- **状态**：空态 = 一句话 + **一个**主 CTA；AI 处理中 = 骨架/进度 +「识别中 / 转写中 / 生成中」
- **待确认**：全局统一虚线边或「待确认」标签，与已入档明确区分

## 5. 页面清单与逐页要求

共 12 页。下列为**必须出现的内容块**；构图在气质约束内由你设计。

### P1 登录
- 价值主张一字不改气质：「看完医生，收好报告，知道下一步」
- 手机号 + 验证码、协议勾选
- **一键体验示范档案**（演示主入口）
- 品牌：字标或极简叶芽图形即可，**禁止插画大图占首屏**

### P2 首次建档（一张卡）
- 三选一：备孕中 / 怀孕中 / 宝宝已出生
- 怀孕中只填预产期；已出生只填出生日期；备孕可跳过日期
- 一个「开始」主按钮；**禁止更多字段**

### P3 批量导入存量报告
- 引导：「把攒下的报告一次收进来，大约 10 分钟」
- 连拍 / 相册多选
- 列表行：缩略图 + 日期/医院/类型（可改）+ 确认；顶栏进度「已确认 3/12」；「稍后继续」

### P4 此刻（默认首页 · 全原型最重要）

**构图铁律（一屏一构图，不是仪表盘）：**

| 区域 | 要求 |
|---|---|
| 首屏必须（不滚动） | ① 大标题「此刻」+ 日期副文案 ② **孕周主视觉**（大数字「24」+「周 +3 天」+ 一句阶段描述 + 细进度条）③ **下一步**分组（2–4 行） |
| 首屏以下（可滚动） | ④ 下次就诊带什么（可折叠）⑤ 轨迹一瞥（2–3 个数值块 + 微型走势）⑥ 最近就诊摘要 |
| 禁止出现在首屏 | 运营 Banner、多组 KPI、无关快捷入口矩阵、第二主按钮 |

下一步行必须混合：

- 标准日历项：小标签「参考日程」+ 右侧「设提醒」
- 用户提醒：如「9 月 15 日 · 大排畸」

**完成度标准**：单独截取首屏，应能直接放进发布会 Keynote，且去掉导航后仍一眼知道这是芽纪（品牌色 + 孕周数字气质）。

### P5 档案（时间轴）
- 段控件：全部 / 妈妈 / 胎儿
- 按月分组倒序列表；产检行内直接展示指标（胎心 146、双顶径 58mm…，等宽数字）
- 顶部入口「阶段小结」；搜索框

### P6 报告确认（AI 解读主舞台 · 阶段 A 必做）
结构自上而下：

1. 报告原图缩略（可放大）
2. 识别字段编辑区（低置信度用 `--accent` **细点**，禁止大红恐吓块）
3. **白话解读**区：浅 `--brand-soft` 底；视觉上明显是「解读」；**每条末尾必须有出处小字**（可点）：`报告原文 P1` 或 `参考：孕中期糖耐说明`
4. **建议下一步** 2–3 条，右侧「采纳」轻按钮（仅提醒 / 携带 / 叮嘱类，禁止「该做检查」类措辞）
5. 底部固定文案（第 8 节）+ 主按钮「确认归档」

### P7 就诊录音
- 进入即**一屏一事**：大录音按钮；录制中呼吸波纹 + 计时；顶部小字用第 8 节录音文案
- 录后：转写文本 + 三组抽取（叮嘱 / 用药 / 下次检查），可编辑删除；主按钮「确认入档」

### P8 阶段小结
- 范围：近 1 / 3 / 6 个月 / 整个孕期 → 生成中 → 六分区：时间线、指标变化（简洁折线）、医院结论摘录（带来源可点）、叮嘱与用药、**未闭环**（示例文案见第 6 节）+「设提醒」、同类检查记录
- 底部固定文案 +「生成给家人讲的简版」

### P9 健康
- 分段：妈妈孕期 / 产后 / 宝宝
- 指标列表：最新值大数字 + 微型趋势；详情：折线 + 历史（来源：手动 / 报告 / 居家监测）
- 「记一条」浮层：选指标 → 输值 → 完成，≤ 三步

### P10 我的
分组列表：家庭成员、完善档案、**信任承诺**、隐私与数据、关于

### P11 家庭成员
成员列表（字头像、关系、可查看/可编辑）、「邀请另一半」→ 弹层权限二选一（人话）

### P12 信任承诺
一屏排版：三条承诺（加密存储 / 绝不用于模型训练 / 随时导出与删除即删除），每条一段人话。**排版质感代表产品人格，值得花心思。**

## 6. 示范数据要求

- 示范家庭：孕 **24 周 +3**；预产期虚构为次年 1 月下旬
- 8–12 条历史事件：含 2 次产检报告、1 条录音、若干居家体重/血压
- 数值合理：胎心 140–150；双顶径与孕周匹配；血压约 110/70
- 解读至少一条「术语安抚」：如「胎盘 II 级」白话解释 + 出处
- 至少一条未闭环：「6 月 3 日报告建议两周后复查血常规，档案中未见记录」
- 至少一条标准日历：「孕 24–28 周：糖耐量筛查」+「参考日程」

## 7. 必须可点通的演示流程

1. 登录 → 一键体验 → 此刻
2. 新用户：登录 → 极简建档（怀孕中，只填预产期）→ 此刻（有标准日历，非空壳）
3. ＋ → 上传报告 → 识别中 → 确认页（改字段、读解读、采纳建议）→ 归档 → 此刻有变化
4. ＋ → 就诊录音 → 录制动画 → 转写抽取 → 确认入档
5. 档案 → 阶段小结 → 近 3 个月 → 六分区 → 未闭环设提醒
6. 此刻 → 轨迹一瞥 → 健康详情 → 记一条居家体重

阶段 A 至少打通流程 1 与流程 3 的「确认页」部分。

## 8. 固定文案（一字不改）

| 位置 | 文案 |
|---|---|
| 报告解读处 | `AI 整理结果仅供记录，请以原始报告和医生意见为准。` |
| 阶段小结处 | `小结仅汇总您的档案记录，不构成医学结论，请以医生意见为准。` |
| 标准日历项 | `参考日程，以医生安排为准` |
| 录音页 | `录音仅存入您自己的档案；请遵守就诊场所相关规定。` |

文案基调：短句、人话、像可靠家人；不卖萌、不营销、不恐吓。称呼用「你」。

## 9. 红线（命中任一条即返工）

1. 紫色 / 蓝紫渐变、彩虹渐变、玻璃拟态滥用、多层重阴影、发光
2. emoji 当图标；彩色拟物图标；图标风格混用；满屏胶囊标签
3. 运营 Banner、轮播、九宫格、资讯流、勋章打卡
4. 首屏塞满无留白；一屏两个以上主按钮；「此刻」做成仪表盘 KPI 墙
5. 诊断/建议措辞：「高风险」「建议服药」「该做/不该做某检查」、评价医生
6. AI 与已确认内容不区分；解读**无出处**
7. 死按钮；中英混排混乱；关键数值被截断或非等宽数字
8. 私自配色、混用圆角/间距；奶油杂志风或报纸密排风
9. 未做阶段 A 验收就铺开全部 12 页（流程违规）
