# 敏感数据地图

| 数据类别 | 示例字段 | 用途 | 存储 | 访问者 |
|---|---|---|---|---|
| 账号标识 | 手机号密文/哈希、显示名 | 登录与账号 | PostgreSQL | 用户本人、服务端鉴权 |
| 家庭关系 | 家庭名、成员关系、角色 | 协作与展示 | PostgreSQL | 家庭成员（按角色） |
| 孕育档案 | 孕期日期、宝宝出生日期 | 建档与上下文计算 | PostgreSQL | EDITOR+ 写，VIEWER 读 |
| 事件与备注 | 标题、备注、医院 | 时间轴 | PostgreSQL | 家庭成员按角色 |
| 医疗报告原文 | OCR 全文、字段、表格 | 归档与核对 | PostgreSQL（受限） | EDITOR+；确认后家庭可读 |
| 原始附件 | 报告图片/PDF | 证据留存 | 私有对象存储 | 短时签名 URL |
| 健康指标 | 体重、血压、身高等 | 趋势展示 | PostgreSQL | 家庭成员按角色 |
| 提醒 | 时间、类型 | 待办 | PostgreSQL + 本地通知 | 家庭成员按角色 |
| 同意记录 | 协议版本、授权时间 | 合规 | PostgreSQL | 用户本人、OWNER |
| 审计日志 | 动作、资源类型（脱敏） | 追溯 | PostgreSQL | OWNER / 运维（受限） |

## 禁止

- 公开永久 URL 暴露附件  
- 日志/埋点写入手机号、报告原文、健康数值  
- 未经确认写入正式档案  
- 向广告或训练平台传输健康数据  

## 同意分项

1. 服务协议与隐私政策  
2. 敏感健康信息处理  
3. 家庭共享  
4. OCR/云处理告知（首次上传前）
