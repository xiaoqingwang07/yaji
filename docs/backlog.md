# 待办与边界

> 对齐 2026-08-08 访谈收敛版定位（[product-positioning.md](./product-positioning.md)）。

## P1（不阻塞 MVP）

- 一页纸就诊摘要（近期指标、在用药、上次医嘱，给医生看）  
- 完整家庭角色矩阵、角色调整与审计日志（MVP 收敛为可查看/可编辑二选一）  
- 基于个人档案的自然语言查询  
- 服务端远程推送与重复提醒  
- PDF 档案导出与打印排版  
- 孕期体重/宝宝生长百分位参考曲线  
- 发票与报销深度管理（MVP 仅事件级金额+说明）  
- 备孕/试管流程引导（MVP 备孕仅归档）  
- 更细产后恢复量表  
- 多孕期客户端切换  
- 弱网续传、离线草稿、跨设备冲突  

## 明确不做

- AI 行动建议（该补什么/该不该做检查/用药推荐）与医生评判  
- 疾病诊断、风险预测、开放式医疗问答  
- 医生端 / 医院对接 / HIS·EMR·医保 / 挂号排队缴费  
- 在线问诊、人工审核  
- 母婴社区、资讯流、电商会员、广告、打卡催办类运营通知  
- 喂奶、睡眠、排泄、尿布等高频生活记录  
- 老人端与多级权限  
- 人脸识别影集、知识图谱、自训练医疗模型  
- 多胎专用交互  
- Web 管理后台（除本地调试）
