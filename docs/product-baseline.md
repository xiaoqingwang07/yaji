## ONBOARD — 首次建档

| 编号 | 需求 | 范围 |
|---|---|---|
| ONBOARD-001 | 创建家庭与妈妈档案；关系可默认，允许后补 | MVP |
| ONBOARD-002 | 选择阶段：备孕中 / 怀孕中 / 宝宝已出生未满 1 岁（备孕仅归档，无流程引导） | MVP |
| ONBOARD-003 | 怀孕中：预产期或末次月经至少一个（首次优先预产期） | MVP |
| ONBOARD-004 | 已出生：宝宝出生日期必填；边界自然日校验 | MVP |
| ONBOARD-005 | 中途退出可继续未完成建档 | MVP |
| ONBOARD-006 | 建档成功生成系统事件；已出生生成出生基线 | MVP |
| ONBOARD-007 | 首次建档极简：登录后一张卡，直达「此刻」 | MVP |

## NOW — 此刻主线

| 编号 | 需求 | 范围 |
|---|---|---|
| NOW-001 | 默认首页展示当前节点（孕周/月龄） | MVP |
| NOW-002 | 下一步清单来自提醒、医嘱、已确认报告建议 | MVP |
| NOW-003 | 下次就诊携带清单 | MVP |
| NOW-004 | 轨迹一瞥与最近就诊摘要 | MVP |
| NOW-005 | 内置标准日历：孕期产检时刻表、0–1 岁疫苗计划、产后 42 天复查等节点，按预产期/出生日期匹配当前阶段，可一键转提醒；标注为参考日程而非医疗建议 | MVP |
| NOW-006 | 关键节点材料清单（含建档证件等非医疗材料），来源官方可靠 | MVP |

## AI — 档案内解读与建议

| 编号 | 需求 | 范围 |
|---|---|---|
| AI-001 | 白话解读仅基于本报告原文，确认前不入库 | MVP |
| AI-002 | 建议下一步：提醒/携带/医嘱，用户采纳后生效 | MVP |
| AI-003 | 不做诊断、风险预测、用药推荐、开放式保健问答 | MVP |
| AI-004 | 阶段小结：按时间范围跨报告事实汇总（时间线、指标变化、结论原文汇编、叮嘱/用药汇总、未闭环复查项、同类检查记录）；仅基于已确认档案、仅引用原文，不产生新医学结论，带固定免责文案 | MVP |
| AI-005 | 白话解读与术语解释标注官方指南出处 | MVP |
| AI-006 | 边界四层模型：只做①术语/报告解释与②档案事实提示；不做③行动建议与④医生评判 | MVP |

## VOICE — 就诊录音

| 编号 | 需求 | 范围 |
|---|---|---|
| VOICE-001 | 一键就诊录音；支持导入手机已有录音文件 | MVP |

| VOICE-004 | 录音入口提示遵守就诊场所规定 | MVP |

## EVENT — 时间轴 / 档案

| 编号 | 需求 | 范围 |
|---|---|---|
| EVENT-001 | 档案时间轴倒序展示关键事件；默认首页为「此刻」 | MVP |
| EVENT-002 | 事件增删改查（软删除） | MVP |
| EVENT-003 | 按主体、阶段、类型、日期筛选 | MVP |
| EVENT-004 | 关键词搜索标题/备注/报告摘要/医院 | MVP |
| EVENT-005 | 支持规定事件类型枚举 | MVP |
| EVENT-006 | 自动展示孕周、产后天数、宝宝日龄/月龄 | MVP |
| EVENT-007 | 事件可关联多附件与多报告；报告仅归属一个正式事件 | MVP |
| EVENT-008 | 事件可选记录费用（金额+说明），轻量不做发票管理 | MVP |

## REPORT — 通用 OCR 归档

| 编号 | 需求 | 范围 |
|---|---|---|
| REPORT-001 | 支持 JPG/PNG/PDF，单文件 ≤15MB | MVP |
| REPORT-002 | 多图/多页 PDF，最多 20 页、总量 ≤50MB，可排序 | MVP |
| REPORT-003 | 私有对象存储，短时签名 URL | MVP |
| REPORT-004 | 报告状态完整可见 | MVP |
| REPORT-005 | 未知类型不提示“不支持”，退回通用模式 | MVP |
| REPORT-006 | OCR 提取基础字段、动态字段、表格、全文 | MVP |
| REPORT-007 | 低置信度醒目标记；可编辑/删除/补充 | MVP |
| REPORT-008 | 用户确认后才写入正式档案 | MVP |
| REPORT-009 | OCR 完全失败仍可手动归档 | MVP |
| REPORT-010 | 确认页固定医疗边界提示文案 | MVP |
| REPORT-011 | 存量批量导入：连拍/多选批量上传，逐份粗识别，列表式快速确认，进度可中断保留；整体 ≤10 分钟完成 | MVP |

| 编号 | 需求 | 范围 |
|---|---|---|
| FAMILY-001 | 关系（展示用）与权限分离 | MVP |
| FAMILY-002 | OWNER 邀请成员，权限二选一：可查看 / 可编辑 | MVP |
| FAMILY-003 | 一次性有限期邀请令牌 | MVP |
| FAMILY-004 | 移除成员（二次确认）；角色调整与审计日志 | P1 |
| FAMILY-005 | 只读成员写操作 403；保留至少一个 OWNER | MVP |
