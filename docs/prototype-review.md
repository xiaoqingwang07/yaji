## 产品主线（已在访谈中确认）

从备孕到宝宝一岁：**收好报告与录音 → 白话看懂（标官方出处）→ 串懂几个月（阶段小结）→ 知道节点与下一步 → 下次带对材料。**

AI 只做①术语/报告解释与②档案事实提示；不做③行动建议与④医生评判。

---

## 原型确认时请重点看

1. **极简开始**：三阶段建档（备孕/孕期/已出生）→「此刻」，是否够轻  
2. **存量导入**：一大袋报告 10 分钟收进来的流程，是否可行、不烦  
3. **就诊录音**：一键录音 → 转写 → 医嘱/用药/下次检查抽取 → 确认，是否顺  
4. **「此刻」首页**：节点、标准日历下一步、携带清单（含材料清单）、轨迹一瞥，是否一眼有用  
5. **报告确认**：白话解读（带出处）+ 建议下一步 + 确认归档，是否清楚  
6. **阶段小结**：跨报告汇总的分区与转述老人用的简化版，是否符合预期  
7. **视觉**：简洁、优雅、强大；界面好看、操作高效，是否达标  

---

## 建议体验路径

1. 打开 App →「一键体验 · 孕期示范」  
2. 看「此刻」：孕周节点、标准日历下一步、携带清单、胎儿指标  
3. 添加 → 上传检查报告 → 读白话解读 → 采纳建议 → 确认归档 → 回到此刻  
4. 添加 → 就诊录音（示范音频）→ 转写抽取 → 确认  
5. 档案 → 阶段小结 → 选近 3 个月  
6. 新用户路径：退出 → 开始使用 → 三阶段入口各试一遍
