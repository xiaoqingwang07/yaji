# 芽纪移动端原型 UX 体验报告（第三轮）

**日期**：2026-08-08（第三轮）  
**对照**：R1 `ux-review-pregnant-pm-2026-08-08.md` · R2 `…-r2.md`  
**标准**：极度挑剔；**简洁优雅 × 功能强大** 双高线——少不等于弱，满不等于强。  
**原型**：Expo Web `http://localhost:8082` · 390 逻辑宽点按  
**截图**：`docs/ux-screenshots-2026-08-08-r3/`  
**身份**：资深互联网产品经理（同类产品用过无数）× 孕约 4 个月宝妈（示范档案孕 24+3）

---

## 1. 评判标尺（先立规矩）

本轮不用「比上轮好一点」当及格线。及格线是：

| 标尺 | 含义 |
| --- | --- |
| **简洁** | 默认一屏只回答一个主问题；次要信息可展开，且展开后仍可读 |
| **优雅** | 视觉一体、文案无撞车、交互语言统一；去掉任何一项不伤理解 |
| **强大** | 诊后闭环真的短：收 → 懂 → 下一步 → 趋势 → 信任；关键能力不藏、不碎、不靠用户猜 |

未同时满足「看起来安静」和「用起来有力」，只算半成品。

---

## 2. 总体结论

**一句话**：芽纪已经接近「会呼吸的家庭档案」外形——此刻干净了、档案会讲主次了、健康默认看见胎心了——但距离「优雅且强大」仍差**产品密度的精修**：有折叠，却缺叙事；有趋势词，却不够可信；有闭环，却仍偏长、偏碎、偶发冗余。

| 维度 | R2 | **R3** | 是否过双高线 |
| --- | ---: | ---: | --- |
| 美感 | 8.0 | **8.0** | 半过：气质对，Web/装饰细节未封顶 |
| 简洁 | 7.5 | **8.0** | 接近：此刻首屏合格；档案列表仍密 |
| 优雅 | 7.5 | **7.5** | 未过：∨∧ 未全站统一；文案仍有重复 |
| 信任 | 8.0 | **8.0** | 过：边界稳定 |
| 情绪价值 | 8.0 | **8.0** | 过：温暖未崩 |
| **功能强度** | 7.5 | **7.5** | 未过：闭环有了，深度与效率未到「强大」 |

**IA**：底栏四 Tab；「收下报告」入口清晰。正确，无需回退。

## 3. 本轮已兑现的改进（诚实肯定）

走查所见（`r3-01`～`r3-04`）：

1. **此刻副文案变短**：「9 月 15 日 · 已预约」——比「携带医保卡…」那一长串克制。  
2. **「收下报告」**取代「收进来」——与折叠「收起」不再撞车。  
3. **「痕迹与携带」**替代工程师腔「更多」。  
4. **档案排序**：超声/产检压在居家监测之前——叙事对了。  
5. **筛选与小结合并折叠**——顶栏少一层常驻噪音。  
6. **健康默认「胎儿」**，胎心 +「近几次略降」露出——情绪主指标终于在首屏。  
7. **报告白话仍置顶**，字段可折——诊后「先懂再核」路径成立。

这些是真进步，不是 PPT。

## 4. 分屏深刺（挑剔正文）

### 4.1 「此刻」——简洁已及格，强大未到

截图：`r3-01-now.png`

**过关之处**  
一屏主问题清楚：**我在第几周？下一件要紧事是什么？** 折叠策略正确。叶芽 + 孕周卡仍是品牌记忆点。

**刺点**

1. **「未闭环」重复**  
   标题已写「复查血常规（未闭环）」，副文案又是「待安排 · 未闭环」。优雅产品不说两遍同一个词。  
2. **「完成」仍是列表主按钮**  
   对「已预约大排畸」而言，主操作更该是「看详情 / 带什么」，而不是「完成」。功能强大 ≠ 处处打勾。  
3. **∨ 展开出现三次**（孕周细节 / 另 1 条 / 痕迹与携带）  
   交互语言统一了用词，但**同屏三次开合**仍像设置页。优雅做法：孕周细节点整卡展开；下一步「另 N 条」用行内轻链；底部一块折叠即可。  
4. **「痕迹与携带」摘要截断**「最近就诊」变成「最…」——不优雅。  
5. **功能缺口**：点「大排畸」不能直达携带清单或事件；「强大」应是一点即达上下文，而不是只剩「完成」。

**宝妈一句**：我终于不被信息淹，但「未闭环未闭环」看得心烦。  
**PM 一句**：安静了，还没「好用到不愿回到备忘录」。

### 4.2 「档案」——主次对了，密度仍不及格

截图：`r3-02-archive.png`

**过关之处**  
报告优先、监测靠后——这是档案产品该有的**权力结构**。列表去色块墙后呼吸感在。

**刺点**

1. **每条仍是四行信息**（类型+时间 / 标题 / 医院 / 指标）——「轻」了视觉符号，没减认知行数。强大档案会用**可变密度**：默认两行（标题+一句结果），展开再医院与指标。  
2. **「筛选与小结」捆在一起**语义怪——筛选是过滤，小结是生成。优雅应是列表角上一句「阶段小结 ›」，筛选用轻 Chip 或下滑手势，不必塞进同一折叠标题。  
3. **日期仍是 `2026-07-22 10:30` 机读格式**——对宝妈不温柔，对品牌不优雅。  
4. **功能缺口**：列表看不到「这篇报告我看懂了吗 / 有没有未闭环」——档案强大应回显此刻的状态，而不是只做时间胶囊。

### 4.3 「健康」——承诺「连成线」，交付仍偏弱

截图：`r3-03-health.png`

**过关之处**  
默认胎儿、胎心可见、「近几次略降」——方向对。

**刺点（严厉）**

1. **「略降」在胎心场景危险**  
   146 相对历史略降，宝妈可能解读为「不好了」。产品边界是不做评判，但**趋势文案本身会制造评判感**。要么加「仍属常见波动区间（非医学判断）」，要么只写「较上次变化」中性词，要么默认不强调升降。  
2. **双顶径无趋势点 / 无短句**——卡片能力不一致，不优雅。  
3. **下半屏空洞**——不是高级留白，是能力空白。强大健康页应至少：主指标大卡 + 一条「与档案同源」的时间轴跳转，而不是两张卡然后真空。  
4. **点阵趋势仍弱于「线」**——文案承诺「连成线」，视觉仍是点。未兑现承诺 = 不信任。

### 4.4 报告确认——强大的核心页，仍偏「说明书长」

截图：`r3-04-report-review.png`

**过关之处**  
白话优先、安抚「胎盘 II 级」、关键指标、字段折叠、免责——这是芽纪差异化最硬的一页。

**刺点**

1. **白话三条 + 三处「报告原文 P1」**——链接重复，噪音。一处出处入口即可。  
2. **字段折叠按钮仍写「展开」**，未用「∨ 展开」——全站语言未收口。  
3. **建议下一步三连「采纳」**——强功能，弱编排。默认勾选「高置信建议」、一键「采纳并归档」才配得上「强大」。  
4. **一屏装不下闭环**——「懂」与「做」仍要滚动。真正优雅的确认页：上半懂完，底栏固定「确认归档」，建议进二级或折叠。

### 4.5 登录 / 演示（轻刺）

宽屏 Web 登录仍贴左簇拥——演示即扣分。示范入口仍偏工程。强大产品会把「样例家庭」做成正式体验模式，而不是折叠链接。

## 5. 任务闭环评分（功能强大专项）

| 任务 | 是否短 | 是否深 | 分 |
| --- | --- | --- | ---: |
| 收下报告 | 短 | 中（识别→确认完整） | 8.0 |
| 看懂报告 | 中 | 强（安抚+出处） | 8.5 |
| 知道下一步 | 短 | 弱（缺跳转上下文） | 7.0 |
| 看见趋势 | 短 | 弱（词强于图，有惊吓风险） | 6.5 |
| 家庭信任 | 中 | 中（入口在，未本轮重测深页） | 8.0 |

**综合**：「收与懂」开始像产品；「串与推」仍像原型。

---

## 6. 与「简洁优雅 × 功能强大」的差距清单

### P0（伤优雅或伤信任）

1. **趋势文案「略降/略升」的惊吓风险**——改中性或加边界句。  
2. **「未闭环」标题+副文案双重重复**。  
3. **报告页「报告原文 P1」重复堆叠**。

### P1（阻「强大」）

4. 下一步主 CTA 从「完成」改为情境动作（详情 / 带什么 / 设提醒）。  
5. 档案列表默认两行密度；医院与多指标进展开。  
6. 健康兑现「线」：真折线或至少「上次 → 这次」数值对读；补齐各卡能力。  
7. 确认页：建议批量采纳 + 吸底主按钮；折叠控件文案统一 ∨∧。  
8. 同屏折叠次数降到 ≤2。

### P2（精修）

9. 日期人性化（「7 月 22 日」）。  
10. 「筛选与小结」拆名或拆入口。  
11. 痕迹摘要勿截断关键词。  
12. 登录限宽居中。

## 8. 竞品坐标（R3）

```
社区运营 ←————————●→ 家庭档案     （外形已靠右）
冷仪器   ←——————●——→ 有温度       （温度在，专业深度不够）
拍了就问 ←———●——————→ 先档后懂     （确认页是王牌，勿稀释）
碎记录   ←————●————→ 能串成故事   （排序有了，密度叙事未完）
```

相对 R2：外形更干净；**「强大」几乎没涨分**——因为强大靠深度与动作设计，不靠再折叠一次。

## 9. 下一轮只准做 5 刀（按影响力）

1. **消重复与惊吓**：未闭环去重；趋势词中性化 + 边界。  
2. **下一步情境 CTA**：完成降级，详情/携带升级。  
3. **档案可变密度**：默认两行，展开见医院与指标。  
4. **健康兑现「线」+ 卡片能力一致**。  
5. **确认页收束**：出处不重复、建议可批量、折叠文案统一、主按钮吸底。

做完这五刀，再谈视觉雕花。
