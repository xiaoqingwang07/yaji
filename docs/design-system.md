# 芽纪 · 视觉与设计系统

> 文档版本：2026-08-08  
> 实现位置：`apps/mobile/constants/theme.ts`、`apps/mobile/components/ui.tsx`、`MetricVisual.tsx`  
> 气质目标：**简洁、温暖、安静、可信**——马卡龙柔色 + 叶芽字标 + 家人语气；有情绪价值，不是冷冰冰的医疗工具。

---

## 1. 设计原则

| 原则 | 要求 |
|---|---|
| 少即是多 | 首页只回答：节点 / 下一步 / 带什么 / 成长痕迹一眼 |
| 有温度 | 文案像可靠家人；数字旁有一句情绪承接，不做卖萌恐吓 |
| 品牌可识别 | 叶芽字标（薄荷绿+蜜桃）+「芽纪」字标；柔光氛围底 |
| 内容优先 | 数字与事实清晰；装饰服务情绪，不抢内容 |
| 触控友好 | 点击目标 ≥ 44×44 pt；支持系统字号增大 |
| 私密安静 | 无资讯流、无运营贴纸、无夸张渐变光效 |

**避免的 AI 审美套路**：紫白渐变主题、奶油底 + 衬线 + 陶土强调的套版、报纸风密排、多层阴影、满屏胶囊标签。

## 2. 设计 Token

实现以代码为准；下表为文档基线。

| Token | 值 | 用途 |
|---|---|---|
| `color.brand` | `#7EB8A8` | 薄荷绿主色、轻强调 |
| `color.brandDark` | `#4F8A7A` | 主按钮、选中态（保证对比度） |
| `color.brandSoft` | `#E4F2ED` | 选中底、轻标签 |
| `color.accent` | `#F0B7A4` | 蜜桃点缀（录音、待办） |
| `color.bg` | `#FBF6F2` | 奶油雾底 |
| `color.surface` | `#FFFFFF` | 内容面 / 列表行底 |
| `color.text` | `#3D342F` | 主文字（暖灰棕） |
| `color.textMuted` | `#9A8B82` | 次要文字 |
| `color.rose` / `lemon` / `sky` | 马卡龙辅色 | 指标色块背景 |
| `metricPalette` | 心/尺/体重/血压/宝宝 | 报告共性数据可视化 |
| `radius.md` | 14 | 分组块圆角 |
| `space` | 4 的倍数 | 间距 |
| 字体 | 系统优先 | 正文清晰，标题克制 |

首版仅简体中文竖屏。日期与日历按 `Asia/Shanghai`。

## 3. 布局与组件约定

### 导航

- 底部 Tab：此刻 / 档案 / 健康 / 我的（无独立「添加」Tab）  
- 添加入口文案统一为「收下报告」（档案顶栏 + 此刻轻链）；打开 `/add-menu` 三主入口  
- 折叠交互统一「∨ 展开 / ∧ 收起」；「此刻」次要区命名「痕迹与携带」  
- 报告共性指标用 `MetricIcon` / `MetricStrip` 几何色块呈现，不用 emoji  


- Tab 一级页：**不重复**底部导航页名；顶区用日期 / 家庭名 / 问候 / 一句承接文案  
- 二级页：标准导航栏标题

### 列表与分组

- 优先 **iOS 风格分组列表**：组标题 + 白底行 + 行内分割  
- 卡片仅在承载可交互块时使用；能用列表不用卡片堆叠  
- 空态：一句暖说明即可；**不**再放与底部「添加」重复的 CTA  
- 录入入口唯一：底部 Tab「添加」；健康/档案页不做第二套录入按钮  
- 有系统导航标题的二级页，页内不再写同名大标题  
- 调试/示范入口默认隐藏（登录折叠；我的连点 Logo 五次）

### 按钮与表单

- 主按钮：品牌色填充；次按钮：文字或轻底  
- 表单：标签在上、字段清晰；错误在字段旁即时提示  
- 危险操作：二次确认；文案直白（删除 / 退出）

### 报告与 AI 区块

- 白话解读、建议下一步与「原始字段」分区清晰  
- AI 区块始终带固定医疗边界提示  
- 低置信度字段用 accent 轻提示，不恐吓式大红块

---

## 4. 「此刻」首页构图

第一屏应读作**一个完整构图**，不是仪表盘拼盘：

1. 品牌/当前阶段气质（克制）  
2. **当前节点**（孕周或月龄）— 主视觉信息  
3. **下一步**清单  
4. **携带清单**（若有下次就诊）  
5. 轨迹一瞥 / 最近就诊摘要  

禁止：首屏塞运营 Banner、多组统计条、无关快捷入口矩阵。

---

## 5. 动效

- 用途：建立层级与反馈（进入、确认、完成），不是装饰噪音  
- 过渡短、缓动自然；列表刷新用轻量反馈即可  
- 首版不强制复杂转场；至少保证：页面切换、主按钮反馈、确认成功反馈清晰

---

## 6. 无障碍与可读性

- 对比度满足正文可读  
- 不依赖颜色单独传达「错误 / 低置信度」（配合文案或图标）  
- 触控间距充足；长文案可滚动，不截断关键医疗数字
