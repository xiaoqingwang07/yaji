# 芽纪 · 交互与信息架构

> 文档版本：2026-08-08 v3（对齐访谈收敛版定位）  
> 产品定义见 [product-positioning.md](./product-positioning.md)

---

## 1. 产品气质

属于家庭的孕育档案与解读助手。界面安静、可信、系统感强；以「此刻」回答当下，以「档案」承载完整历史。无社区流、无运营 Banner、无打卡催办。

录入速度是硬指标：**拍报告归档、记叮嘱 ≤ 30 秒；存量批量导入 ≤ 10 分钟。**

---

## 2. 信息架构

```text
底部 Tab
├── 此刻（默认首页）
├── 档案（时间轴历史 + 阶段小结入口）
├── 健康（同源趋势）
└── 我的（家庭 / 隐私 / 完善档案 / 信任承诺）

全局添加入口（出诊场景优先）
├── 就诊录音（诊室内一键开始）
├── 上传检查报告
├── 记下医生叮嘱
├── 记录用药
├── 记居家监测（体重 / 血压 / 胎心）
└── 手动事件 / 提醒（次要）
```

提醒并入「此刻 → 下一步」，不单独占 Tab。

---

## 3. 页面清单

### P01 登录

手机号、验证码、协议；一键体验示范。价值主张：**看完医生，收好报告，知道下一步。**

### P02 首次建档（极简）

一张卡完成，三阶段：

| 阶段 | 必填 |
|---|---|
| 备孕中 | 无必填日期（可选开始备孕时间） |
| 怀孕中 | 预产期（或末次月经） |
| 宝宝已出生未满 1 岁 | 出生日期 |

家庭名、关系默认生成，可后补。成功后直达「此刻」。

### P02b 存量批量导入（S0，建档后引导，可跳过）

1. 引导文案：把攒下的报告一次收进来（预计 10 分钟）  
2. 连拍 / 相册多选 / PDF 多选 → 批量上传  
3. 逐份自动粗识别：类型、日期、医院（可信度低就留空）  
4. 列表式快速确认：滑动核对日期与类型即可入档，字段细节以后再补  
5. 随时中断，进度保留；导入结果直接构成时间轴

### P03a 此刻（默认首页）

| 区块 | 内容 |
|---|---|
| 当前节点 | 备孕中 / 孕周 / 宝宝月龄日龄 |
| 下一步 | 两层来源：① 内置标准日历（产检时刻表、0–1 岁疫苗计划、产后 42 天复查等，按节点匹配，可一键转提醒）；② 提醒、医嘱、已确认报告建议 |
| 携带清单 | 下次就诊建议携带的既往结果 + 节点材料清单（如建档所需证件） |
| 轨迹一瞥 | 关键指标近期变化（含居家监测） |
| 最近就诊 | 最近一次报告 / 录音 / 事件摘要 |

标准日程条目标注「参考日程，以医生安排为准」。备孕阶段无标准日历，以最近检查与提醒为主。新建档用户凭标准日历即有内容，空态弱化。

### P03b 阶段小结（跨报告汇总）

入口：「此刻 → 轨迹一瞥」与档案页顶部。

1. 选时间范围：近 1 / 3 / 6 个月，或整个孕期 / 出生至今  
2. 分区展示：检查时间线（时间+医院+项目）、关键指标跨报告变化（引用原始数值）、各医院结论**原文汇编**（标出处，可跳原图）、医嘱与用药汇总、未闭环项（可一键转提醒）、同类检查记录  
3. 只汇总事实、只引用原文；不评价医生判断、不判断检查必要性  
4. 固定文案：`小结仅汇总您的档案记录，不构成医学结论，请以医生意见为准。`  
5. 可生成适合口头转述的**简化版**（给老人讲）

### P03 档案（时间轴）

- 倒序事件列表；筛选：全部 / 妈妈 / 胎儿或宝宝；类型与日期  
- 卡片突出产检关键指标（胎心、双顶径、头围、腹围、股骨长等）  
- 自动展示孕周、产后天数、宝宝日龄/月龄；备孕事件标注备孕期  
- 基础搜索（标题、备注、医院）

### P04 事件详情

结构化字段、备注、附件、来源（拍照/导入/录音/手动）、**费用（可选：金额+说明）**、编辑、软删除。

### P05 手动事件

必填：类型、发生时间、标题；可选备注、地点、主体、费用。

### P06–P08 报告流程

1. 选图/PDF → 排序 → 上传 → 识别中（状态可见）  
2. 确认页：原图对照、动态字段编辑 + 低置信度标记、**白话解读（标注官方指南出处）**、建议下一步（可采纳为提醒/携带）、确认归档  
3. 固定文案：`AI 整理结果仅供记录，请以原始报告和医生意见为准。`  
4. 未知类型退回通用 OCR + 手动补录，不提示「不支持」；完全失败仍可手动归档  

状态：`UPLOADING` → `PROCESSING` → `NEEDS_REVIEW` → `CONFIRMED` / `FAILED`。确认前不进正式档案、搜索与健康趋势。

### P06b 就诊录音（新）

1. 添加菜单首位「就诊录音」：进入即一个大录音按钮，一键开始/结束  
2. 首次使用提示：`录音仅存入您自己的档案；请遵守就诊场所相关规定。`  
3. 结束后自动转写 → 抽取：医嘱、用药、下次检查时间与项目  
4. 确认页核对抽取结果（同报告确认逻辑），采纳项转为叮嘱记录/提醒/携带清单  
5. 原始音频与转写文本留档，可回放；支持导入手机已有录音文件

### P09–P13 健康

分段：妈妈孕期 / 妈妈产后 / 宝宝。最新值、历史列表、简易趋势。**居家监测快速录入**（体重、血压、胎心等，30 秒内完成）。与档案同源，不重复录入；不做诊断与风险预测；单位不静默换算。

### P14–P15 提醒

一次性提醒；完成/修改/取消。来源：手动、标准日历一键转入、报告/录音建议采纳。不自动创建。

### P16 家庭

夫妻共享：邀请成员（一次性有限期令牌），权限二选一（可查看 / 可编辑），移除成员。无角色矩阵、无老人端。

### P17 隐私与信任

- 授权列表、分项同意、导出（JSON+附件）、删除申请  
- **信任承诺明文展示**：加密存储、绝不用于模型训练、随时导出、删除即删除

---

## 4. 通用状态

每个数据页：加载骨架、首次空态（单一 CTA）、失败可重试、无权限提示、删除失效兜底。  
录音/报告类额外：转写中 / 识别中 / 待确认 / 已确认 / 失败。

---

## 5. 主流程（原型须走通）

1. 极简建档（备孕 / 孕期 / 已出生三入口）→ 此刻  
2. 存量批量导入 → 时间轴成形  
3. 上传报告 → OCR → 白话解读（带出处）→ 采纳建议 → 确认归档 → 此刻更新  
4. 就诊录音 → 转写 → 医嘱/用药/下次检查抽取 → 确认入档  
5. 记下医生叮嘱（手动）  
6. 标准日历节点 → 一键转提醒 → 出现在「此刻」下一步  
7. 居家监测录入 → 健康趋势更新  
8. 阶段小结生成与查看  
9. 分娩衔接建议创建宝宝档案 → 产后与宝宝记录（成长/体检/疫苗）  
10. 邀请伴侣共享  
11. 导出 / 删除入口与信任承诺页

---

## 6. 文案基调

- 短、直白、像系统工具；添加菜单优先「刚看完医生」场景  
- AI 相关文案始终带「仅供记录理解 / 以医生意见为准」；解读注明指南出处  
- 不出现「诊断」「高风险」「建议服药」「该做/不该做某检查」等越界措辞  
- 标准日历统一标注「参考日程，以医生安排为准」
