# 测试设计（大步骤一）

## 缺陷等级

| 等级 | 定义 | 发布 |
|---|---|---|
| P0 | 数据丢失、越权、确认前写入正式档案、崩溃阻断主流程 | 阻断 |
| P1 | 主流程无法完成（建档/归档/健康/邀请） | 阻断 |
| P2 | 次要功能缺陷或明显错误状态 | 应修 |
| P3 | 轻微视觉/文案 | 可进发布后 |

## P0 自动化最低集（大步骤二实现）

- 验证码登录与开发登录隔离  
- VIEWER 写接口 403  
- 最后一个 OWNER 不可降级/移除  
- 报告确认前不出现在搜索与健康趋势  
- 确认事务：报告 + 事件 + 可选健康同步幂等  
- OCR 重试不重复创建  
- 手机号不以明文索引存储  

## 手动主路径（第 13.2 节）

1. 孕期建档  
2. 宝宝已出生建档  
3. 手动事件  
4. 超声/检验/未知类型报告归档  
5. 低置信度字段修订  
6. 分娩后建议创建宝宝  
7. 妈妈产后与宝宝成长同源更新  
8. 提醒完成/取消  
9. 邀请接受与权限  
10. 导出与删除二次确认
